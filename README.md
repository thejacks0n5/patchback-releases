# Patchback — downloads

Patchback saves and recalls monitor mixes on Yamaha RIVAGE PM consoles: each
person's mix-bus sends as a named preset, week to week, onto whatever bus they
are on. It also does matrix buses, live drift monitoring, channel-strip
presets, Planning Center plans, undo and weekly auto-archiving.

It runs on Mac and Windows. iPads and other computers on the same network open
it in a browser.

**[Download the latest version](../../releases/latest)**

- **Mac:** the `.dmg` — one download for Apple Silicon and Intel, signed and
  notarized by Apple.
- **Windows:** `Patchback Setup ….exe`. It isn't signed yet, so Windows shows a
  blue "Windows protected your PC" screen: click **More info → Run anyway**.

## First run

- **macOS** asks to allow **Local Network** access. Allow it, or Patchback
  can't reach the console.
- **Windows** may ask about the firewall. Allow it on **private networks** so
  iPads can reach it.
- Closing the window keeps Patchback running in the **menu bar** (Mac) or
  **system tray** (Windows), which is what keeps iPads, live monitoring and
  auto-archive working. Quit from that icon. Its menu also shows the address
  for iPads.

## Updates

Patchback checks for updates on its own and downloads them in the background.
When one is ready, **Restart to update** appears. Nothing installs until you
click it, so you choose the moment. Your mixes and settings are never touched
by an update.

## Notes

- Early software. Try anything new on a spare bus first and read the command
  preview before sending.
- This repository only hosts the downloads; the source code is private.
